"# AI-Powered-Personal-Fitness-Trainer"

Lightweight FastAPI + React project that provides an AI-powered personal fitness trainer API and frontend.

## Architecture

The application follows a full-stack flow:

```text
React + Vite frontend
	|
	v
FastAPI backend and JWT authentication
	|
	v
Postgres in deployment or SQLite for local development
```

The backend connects the user interface to the MediaPipe-based pose-estimation
engine for exercise analysis and the Gemini-based recommendation planner for
adaptive workout plans. Analytics and body measurements are persisted through
the same API and database layer.

**Prerequisites**
- **Python**: 3.11+
- **Node.js & npm**: Node 18+ recommended
- **Database**: Set `DATABASE_URL` to a Supabase/Postgres URL or an explicitly chosen SQLAlchemy-supported database URL.

**Backend — Setup & Run**
- **Create virtualenv**: `python -m venv .venv`
- **Activate**: Windows: `\.venv\Scripts\activate`  mac/linux: `source .venv/bin/activate`
- **Install Python deps**: `pip install -r requirements.txt`
- **Configure database**: create a `.env` file at the project root and set `DATABASE_URL` to your database connection string. The app exits with an error if it is missing; SQLite can be used by explicitly setting a SQLite URL.
- **Apply DB migrations**: `alembic upgrade head`  (If you only need to mark the DB as matching scripts: `alembic stamp head`)
- **Run the API**: `uvicorn backend.main:app --reload --host 0.0.0.0 --port 8000`
- **Health check**: `http://localhost:8000/health`

**Frontend — Setup & Run**
- `cd frontend`
- `npm install`
- `npm run dev`
- Open `http://localhost:5173` (Vite default) to view the app.

**Database migrations**
- Create an autogenerated revision: `alembic revision --autogenerate -m "your message"`
- Apply migrations: `alembic upgrade head`

**Tests**
- Run unit tests: `pytest`

**Notes & Troubleshooting**
- If Alembic fails with missing template `alembic/script.py.mako`, ensure the file exists in the `alembic/` folder (this repository includes a default template).
- If `alembic revision --autogenerate` errors with "Target database is not up to date", run `alembic upgrade head` or `alembic stamp head` first.

### Quick Start
1. Clone the repository
2. Copy `.env.example` to `.env` and fill in your Supabase and Gemini credentials
3. Run `pip install -r requirements.txt`
4. Run `alembic upgrade head` to create database tables
5. Run `uvicorn backend.main:app --reload --port 8000`
6. In a new terminal: `cd frontend && npm install && npm run dev`
7. Open http://localhost:5173
