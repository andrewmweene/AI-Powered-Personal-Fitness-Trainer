# Frontend

This document describes the Streamlit frontend and page layout.

- `frontend/app.py`: Streamlit multipage application entry point.
- `frontend/pages/home.py`: landing page with authentication forms.
- `frontend/pages/exercise.py`: live webcam exercise view with feedback and rep tracking.
- `frontend/pages/dashboard.py`: progress analytics and summary metrics.
- `frontend/pages/workout_plan.py`: generated weekly workout plan display.
